# 名画电影导演（painting-film-director）

一个用于把世界名画改编为真人电影短片的中文提示词 Skill。它会先核对作品背景，区分作品事实、艺术解读和原创情节，再倒推通往原画定格的故事、动作与运镜，最后输出可复制的视频生成提示词。

## 使用

将本仓库作为 `painting-film-director` 技能放入支持 `SKILL.md` 的 Agent 技能目录，然后在对话中提出需求，例如：

> 请用《吻》设计一段 20 秒、16:9 的真人化视频提示词。

输入需要画作名称和时长；画幅比例默认 16:9。可以上传原画，让构图、姿势和颜色更贴近指定版本。

Skill 默认只分析画作并撰写中文提示词。只有用户明确要求生成视频，且当前 Agent 确实有可调用的视频模型时，才会尝试生成视频。
